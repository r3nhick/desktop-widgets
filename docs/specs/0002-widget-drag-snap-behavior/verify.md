# Verify: Розміщення та прилипання віджетів · spec 0002 · updated 2026-09-24

_Steps derived from spec 0002 acceptance criteria. `/check verify` runs these; `/test` locks the durable ones._

> **Поведінка уточнена користувачем під час /develop**: при drop на зайняте місце віджет
> прилипає до краю того віджета, на який наїхав (edge snapping), а не шукає вільну
> клітинку по всій сітці. Якщо всі краї зайняті, віджет лишається там, де кинутий.

## UI / manual

- [ ] Увімкнути edit mode, тягнути віджет поверх іншого (не відпускаючи кнопку) → інші віджети НЕ рухаються, тільки той, що тягнеш, рухається → AC-1
- [ ] Кинути віджет так, щоб він налягав на інший (button release) → віджет плавно (ease) прилипає до найближчого вільного краю того віджета (зліва/справа/зверху/знизу), не лишається поверх нього → AC-2
- [ ] Кинути віджет у бік pinned віджета (або на нього) → pinned залишається непорушним; віджет прилипає поруч на вільну позицію → AC-3
- [ ] Заповнити увесь монітор віджетами (немає жодної вільної клітинки), кинути віджет на зайняту → віджет лишається там, де кинутий (overlap дозволено) → AC-4
- [ ] (Multi monitor) Тягнути віджет у бік іншого монітора → віджет не перестрибує на інший монітор; пошук вільної позиції тільки на поточному моніторі → AC-5
- [ ] Під час активного drag натиснути Escape → віджет миттєво (без анімації) повертається на oldX/oldY, drag state очищується → AC-6
