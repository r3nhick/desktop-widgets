# 🎨 Нове меню додавання віджетів

## ✅ Що встановлено

Успішно додано красиве меню для додавання віджетів з SVG іконками!

### 📁 Створені файли:
- `widgetAddMenu.js` - модуль меню з картками віджетів
- `assets/icons/*.svg` - 12 SVG іконок для віджетів
- `docs/WIDGET_ADD_MENU.md` - повна документація
- Оновлено `extension.js` - інтеграція меню
- Оновлено `stylesheet.css` - стилі для меню та кнопки

## 🚀 Як використовувати

### Крок 1: Перезавантажте GNOME Shell
```bash
Alt+F2 → введіть 'r' → Enter
```
або
```bash
# Вийдіть і увійдіть в сесію
```

### Крок 2: Знайдіть кнопку "+"
Кнопка з'явиться в **правому нижньому куті** екрану:
- Синя кругла кнопка з іконкою "+"
- При наведенні стає світлішою
- При кліку відкривається меню

### Крок 3: Виберіть віджет
1. Натисніть на кнопку "+"
2. З'явиться меню з категоріями віджетів
3. Наведіть на картку віджета (підсвітиться)
4. Клікніть на віджет для додавання

### Крок 4: Налаштуйте віджет
- Віджет з'явиться в центрі екрану з анімацією
- Автоматично увімкнеться Edit Mode
- Перетягніть віджет на потрібне місце
- Змініть розмір кнопкою розміру

## 🔧 Налаштування

### Додати новий віджет в меню

Відредагуйте `widgetAddMenu.js`, додайте в `WIDGET_CATALOG_DATA`:

```javascript
{
  type: 'mywidget',           // має бути в WIDGET_MODULES (extension.js)
  labelKey: 'My Widget',      // назва англійською (для перекладу)
  descKey: 'Description',     // опис англійською
  icon: 'mywidget.svg',       // файл в assets/icons/
  category: 'productivity',   // time/productivity/info/media/system
}
```

### Додати SVG іконку

1. Помістіть `.svg` файл в `assets/icons/`
2. Переконайтеся що SVG оптимізований
3. Вкажіть ім'я файлу в каталозі

## 🐛 Усунення проблем

### Кнопка "+" не з'являється
```bash
# Перевірте чи розширення активне
gnome-extensions list --enabled | grep desktop-widgets

# Перезавантажте розширення
gnome-extensions disable desktop-widgets@r3nhick
gnome-extensions enable desktop-widgets@r3nhick

# Перевірте логи
journalctl -f -o cat /usr/bin/gnome-shell | grep desktop-widgets
```

### Меню не відкривається
1. Перевірте права доступу до `widgetAddMenu.js`
2. Перегляньте логи на помилки JS
3. Перезавантажте GNOME Shell (Alt+F2, 'r')

### Іконки не відображаються
1. Перевірте чи існують файли в `assets/icons/`
2. Перевірте права читання файлів
3. Використовуйте fallback іконки
