## 🚀 Як використовувати

### 1. Перезавантажте GNOME Shell:
```bash
Alt+F2 → 'r' → Enter
```

### 2. Відкрийте налаштування:
```bash
gnome-extensions prefs desktop-widgets@r3nhick
```

### 3. Оберіть спосіб додавання:

**Швидкий (Quick add):**
- Виберіть віджет з dropdown → Add

**Візуальний (Widget gallery):**
- Клікніть "Widget gallery" → Виберіть з діалогу
